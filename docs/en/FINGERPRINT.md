# ovobrowser fingerprint changes

Chinese: [FINGERPRINT.md](../zh/FINGERPRINT.md)

This document lists what the three kernels (138 / 144 / 150) change relative to upstream Chromium / ungoogled-chromium.
Flag syntax, defaults, and pitfalls: [FLAGS.md](FLAGS.md).

Rule: **omit a flag = real hardware / upstream default**. **Pass a flag = spoof or noise as specified**.

---

## 1. Product identity (decoupled from detection-site UA)

The binary product name is `ovobrowser` instead of `Chromium`:

- Task Manager / file properties / AppUserModelID
- `chrome://version` title and wordmark
- Help → About and Settings copy (200+ locales remapped)
- Default profile dir: `%LOCALAPPDATA%\ovobrowser\User Data`

**Intentionally unchanged:**

- `navigator.userAgent` and Client Hints still report Chrome / Chromium / GREASE
- Legal/copyright lines still credit The Chromium Authors

Changing the UA brand to “ovobrowser” would be flagged as an unknown browser.

## 2. Per-category fingerprint noise (5 independent classes)

| Flag | JS / pixel surface | If omitted |
|---|---|---|
| `--fingerprint-canvas[=seed]` | `toDataURL` / `getImageData` / `measureText` | Native canvas |
| `--fingerprint-webgl[=seed]` | WebGL `readPixels` | Native readback |
| `--fingerprint-audio[=seed]` | AudioContext waveform / sample-rate stats | Native audio |
| `--fingerprint-rects[=seed]` | `getClientRects` / `getBoundingClientRect` | Native geometry |
| `--fingerprint-font[=seed]` | Font metrics / available fonts | Native fonts |

- Bare flag: random seed for this process, **stable across tabs in the same run**
- `=number`: fixed seed, reproducible per profile
- `--fingerprint-random`: enable all five (each with a random seed)
- `--fingerprint=<number>`: fallback seed only; **by itself it no longer turns noise on**

Version gaps:

- 138: audio perturbs frame count only; canvas main thread vs Worker not aligned
- 144 / 150: full audio noise; canvas main thread and Worker share the same noise

**FingerprintJS Pro:** noise or GPU-string spoofing often yields Browser Tampering. Stay green by leaving all five off and skipping `--fingerprint-gpu-*`.

## 3. Navigator / UA-CH / hardware

| Flag | Effect |
|---|---|
| `--user-agent=` | `navigator.userAgent` + UA header. Version **must** be `MAJOR.0.0.0` |
| `--fingerprint-brand=` | UA-CH `brands` |
| `--fingerprint-brand-version=` | UA-CH **full** patch (`fullVersionList`) |
| `--fingerprint-platform=` | `navigator.platform` + UA-CH platform: `windows` / `macos` / `linux` / `android` / `ios` |
| `--fingerprint-platform-version=` | UA-CH `platformVersion` (Win11 ≥ `13.0.0`; UA still uses `Windows NT 10.0`) |
| `--fingerprint-hardware-concurrency=` | `navigator.hardwareConcurrency` |
| `--fingerprint-device-memory=` | `navigator.deviceMemory` (`0.25/0.5/1/2/4/8`) |
| `--fingerprint-dnt=` | `navigator.doNotTrack` |
| `--fingerprint-battery=` | `getBattery()` `c,l,ct,dt` |
| `--fingerprint-disable-speech-voices` | `speechSynthesis.getVoices()` returns `[]` |

GREASE brands are generated by Chromium’s native algorithm. `platform=ios` hides `navigator.userAgentData` (real Safari has none).

## 4. Screen + DPR (must be paired)

| Flag | Effect |
|---|---|
| `--fingerprint-screen=WxH` | `screen.width/height/avail*` — **CSS logical pixels** |
| `--fingerprint-device-scale-factor=` | `devicePixelRatio`, CSS `resolution`, `Sec-CH-DPR` |
| `--fingerprint-screen-color-depth=` | `colorDepth` / `pixelDepth` |
| `--fingerprint-screen-width=` / `-height=` | 144/150 legacy split form of `screen` |

Sites display physical resolution as `screen.width × devicePixelRatio`.

Screen without DPR uses the **host** scale and produces impossible sizes. macOS DPR is `1` or `2` only; Windows uses `1/1.25/1.5/1.75/2/2.25` — do not invent `1.33`.

## 5. GPU / WebGPU / Bluetooth / WebRTC

| Flag | Effect |
|---|---|
| `--fingerprint-gpu-vendor=` | WebGL `UNMASKED_VENDOR_WEBGL` |
| `--fingerprint-gpu-renderer=` | WebGL `UNMASKED_RENDERER_WEBGL` |
| `--fingerprint-webgpu=disable` | `navigator.gpu = null` |
| `--fingerprint-disable-bluetooth` | `navigator.bluetooth = null` |
| `--webrtc-ip-handling-policy=` | ICE candidates; prefer `disable_non_proxied_udp` (default, hides LAN IPs) |

Vendor and renderer must be a real paired GPU. Mobile UA + desktop RTX/D3D11 is an instant lie.

## 6. Timezone / language

| Flag | Effect |
|---|---|
| `--timezone=` | JS `Intl` / `Date` IANA zone |
| `--lang=` | UI language + `navigator.language` + default `Intl` locale |
| `--accept-lang=` | `Accept-Language` + `navigator.languages` (**no `q=` weights**) |

Must match the **exit IP**, or BrowserScan hits:

- Different time zones −10%
- Language mismatch −10% (Chinese hosts leak `zh-CN` if you set accept-lang but not lang)

## 7. Behavior and other flags

| Flag | Effect |
|---|---|
| `--blink-settings=imagesEnabled=false` | Block images |
| `--max-image-size-kb=` | Drop images over N KB by `Content-Length` |
| `--autoplay-policy=document-user-activation-required` | Block autoplay |
| `--mute-audio` | Mute |
| `--disable-save-password` | Disable save-password bubble (default is **on**; ungoogled’s false was reverted) |
| `--block-notifications` | Deny notifications only |
| `--deny-permission-prompts` | Deny all permission prompts |
| `--disable-quic` | Required with SOCKS or HTTPS often fails with `ERR_SSL_PROTOCOL_ERROR` |

Default search is restored to Google (ungoogled’s “No Search” / `trk:` prefix removed). Existing profiles refresh via the engine-list version bump.

## 8. Consistency fixes (always on, no flags)

- ClientRects / BoundingClientRect noise is stable across calls
- 144/150: canvas noise matches between main thread and Worker
- UA / UA-CH match the real kernel major version

---

## 9. How to call it

The kernel only reads **command-line flags**. Any language can spawn `chrome.exe` — see `examples/`.

Chromium `--proxy-server` **does not support user/password**. For authenticated residential proxies:

```
browser → local unauthenticated SOCKS5 bridge → (optional) local ladder :7890 → upstream
```

Timezone/language must be set **before** launch; changing `--timezone` later requires a restart.

## 10. Lab notes

- **FingerprintJS Pro green:** no category noise, no GPU-string spoof. Hardware/screen/locale can still be set. Side effect: the real-machine hash is stable, so Velocity can link multiple IPs to one visitor.
- **BrowserScan 100%:** reduced UA + full brand-version; paired screen+DPR; lang + accept-lang + timezone aligned to the exit IP. Noise may not hurt BrowserScan but will trip FingerprintJS Tampering.
- Residential proxy ranges may hit IP Blocklist; that is independent of the kernel.
